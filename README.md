# Daniele D’Orazio — sito dimostrativo

Sito statico responsive, senza dipendenze, tracker o moduli di raccolta dati. HTML semantico, pagine dedicate ai servizi, metadati, Open Graph e JSON-LD WebPage. Illustrazione SVG originale.

## Anteprima locale

```sh
python3 -m http.server 8080
```

## Pubblicazione

GitHub Pages: Settings → Pages → Deploy from a branch → main / (root).

## Dominio danieledorazio.it

Il dominio non è stato ancora collegato. Prima del collegamento verificare il dominio in GitHub e configurare i DNS secondo la documentazione ufficiale di GitHub Pages. Impostare quindi il custom domain nelle impostazioni Pages e abilitare HTTPS. Non è presente un CNAME per evitare di attivare un dominio ancora non configurato.

## Prima del lancio definitivo

- Confermare con Daniele i servizi e tutti i testi dimostrativi.
- Inserire recapiti, iscrizione all’albo e dati fiscali verificati.
- Aggiornare canonical assoluti, og:url, sitemap.xml e la direttiva Sitemap nel robots.txt dal dominio GitHub Pages al dominio finale.
- Aggiungere dati strutturati professionali solo con informazioni reali confermate.
- Registrare il dominio in Google Search Console e inviare la sitemap.

La struttura è predisposta per la ricerca locale; l’indicizzazione e il posizionamento non sono garantiti. I dati di prova sono dichiarati nelle pagine. Non sono stati inventati recensioni, qualifiche aggiuntive, indirizzi, recapiti o risultati professionali.
